# 检索与发布验收

## 检索指标

固定64块语料、查询、事实组标签、候选策略、Top-k及主题保护。每题按必要事实组计算覆盖；任一可接受替代证据命中即算覆盖该组。Recall先按题计算，再取平均。

132道开发／回归题中，113道完整文档题进入主指标。部分资料、工具／会话及模糊题另行诊断，不混入完整文档指标。

| 配置 | 平均事实Recall@5 | 必要证据全部覆盖@5 |
|---|---:|---:|
| 混合检索 | 93.9% | 103/113 |
| 混合检索＋预训练重排 | 97.1% | 106/113 |

这不是最终回答准确率或独立盲测结果。题目、标签、参考排名分别保存在`evaluation/questions.jsonl`及`evaluation/reference_top5.json`；记录的改善不代表每道题都改善。

## 发布迁移检查

从独立Python环境与已批准文本输入重建数据库和64块向量，没有复制旧数据库、旧向量或冻结检索包。在显式固定查询向量的迁移对照中，132题的混合检索Top-5及预训练重排Top-5均与原参考排名一致。

另外检查页面真实默认后端：新生成一题查询Embedding，执行实际CUDA重排，结果与参考排名一致。该检查使用固定离线任务计划，不验证自由文本router或云端生成质量。

282项自动回归通过，覆盖会话更新、收费边界、分类SQL、规则守卫、引用和页面交互；不把单元测试数量当成独立用户问题数量。Streamlit临时端口健康检查及首页均返回HTTP200，测试进程已关闭。

运行所需的已处理语料与结构化输入随仓库提供。发布验收只复制发布清单内文件，模型使用明确指定且逐文件校验的本地缓存，重新生成数据库和语料向量，不复制旧数据库或索引。模型公网下载不是本轮验收范围。

## 运行

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/evaluate.py
```

默认评测会重新生成查询向量。`--query-cache`仅用于明确指定的固定向量迁移比较，不是应用运行依赖。输出保存在被忽略的`artifacts/evaluation/`。
